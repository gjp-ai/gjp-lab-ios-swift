# GJPLab iOS Feature Lab

GJPLab is a small SwiftUI app for learning current iOS fundamentals by reading, running, and extending contained working features. It uses SwiftUI navigation, URLSession, a Slate light/dark design system, Firebase service demonstrations, and a project-local iOS agent-skill library.

Start with the [documentation index](doc/README.md) for architecture, visual-system, splash, Firebase, and agent-skill guidance.
