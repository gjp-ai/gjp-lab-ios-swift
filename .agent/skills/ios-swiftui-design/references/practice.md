# Practice guide

Improve the skill from evidence; a successful local change is not automatically a portable rule.

- Choose a bounded real task such as a screen, an accessible state, a SwiftUI review, or a width adaptation.
- Record the outcome, host architecture, constraints, and available checks before changing anything.
- Evaluate fit, hierarchy, state/effects, accessibility, layout, and verification. For review tasks, evaluate finding correctness and actionability instead.
- Change the reusable skill only when the lesson applies beyond this repository; put local conventions in `AGENTS.md`.
- Prefer a narrow correction to accumulated rules, and report whether practice changed the skill.
